## Safety rules

- Always scope queries by `organization_id`.
- Prefer read-only investigation first; write fixes only with explicit approval.
- Never dump `plaid_item_secrets`, vault secret payloads, or DocuSign/EasyPost keys into docs or tickets.
- Confirm fiscal period openness before advising void/repost actions.
