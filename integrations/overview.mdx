## Shared primitives

| Concept | Table / field | Notes |
| --- | --- | --- |
| Data connection | `data_connections` | Used for cart / WMS / carrier style providers |
| Webhook event | `webhook_events` | Durable inbound event store |
| Activity | `cart_integration_activity` | Human-readable integration activity |
| Audit | `data_audit_events` | Configuration/activity auditing |

## Support rules

- Never paste access tokens, vault secret ids' payloads, or webhook signing secrets into tickets.
- Prefer status fields (`status`, `sync_status`, exception `reason`) over opening vault contents.
- After fixing mappings, retry **one** exception and confirm no duplicate `sales_orders.external_id`.
